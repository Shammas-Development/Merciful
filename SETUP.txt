MERCIFUL HOME CARE SITE SETUP
===============================

The site is a plain static site: no build step, no dependencies. Open index.html
in a browser to preview, or drop the folder on Vercel / any web host.

Pages: index, services, insurance, resources, timesheets, about, careers, contact
Clean URLs (/services, not /services.html) are handled by vercel.json on Vercel
and by .htaccess on Apache hosting. Both are already in the folder.


1. FORMS (required before launch, 2 minutes, free)
---------------------------------------------------
The contact form and the careers application both post to Web3Forms and need one
free access key.

  1. Go to https://web3forms.com
  2. Enter the delivery email:  mercifulhcllc@gmail.com
  3. They email you an "Access Key" (a long code)
  4. In BOTH contact.html and careers.html, find:
         <input type="hidden" name="access_key" value="YOUR_WEB3FORMS_ACCESS_KEY">
     and replace YOUR_WEB3FORMS_ACCESS_KEY with the key
  5. Save. Submissions now arrive at mercifulhcllc@gmail.com

Spam protection (honeypot field) is already built in.


2. INSURANCE CARRIER LOGOS (client requested)
----------------------------------------------
The carrier strip now sits directly under the hero on the home page, and still
shows each carrier as a text wordmark because we do not have logo files yet.

To switch to real logos: drop a file into assets/img/insurance/ using the exact
filename listed in that folder's README.txt. .png is tried first, then .svg,
then .jpg. The page detects the file and swaps the text for the image
automatically. No HTML edit, and if a file is missing the text simply stays
and nothing breaks.

  assets/img/insurance/humana.png       -> replaces the "Humana" wordmark
  assets/img/insurance/aetna.png        -> replaces the "Aetna" wordmark
  ...and so on for all ten carriers

IMPORTANT: these are registered trademarks owned by the insurers. Before
publishing them, get the logo files from each payer's brand/media kit or from
your provider representative, and confirm you are permitted to display them as a
participating provider. Most payers have a provider marketing page with approved
assets and usage rules. Do not pull logos off Google Images.


3. PAYSTUB PORTAL (open item, needs the payroll provider)
-----------------------------------------------------------
timesheets.html has a "Paystubs" section (#paystubs) with a placeholder. Once
the client tells us which payroll system they use (ADP, Paychex, Gusto,
QuickBooks Payroll, etc.), open timesheets.html, find the HTML comment that
starts "PAYSTUB PORTAL:", and follow it: swap the placeholder paragraph for the
provider's employee login URL on a button. It is a one-line change.

Until then the section tells caregivers to call or email the office for a copy,
which is what actually happens today.


4. FORMS AND RESOURCES
-----------------------
resources.html   Caregiver and family resources. Links out to MDHHS, Michigan
                 Medicaid, MI Bridges, Adult Protective Services, Area Agencies
                 on Aging, MMAP, 2-1-1, and the Long Term Care Ombudsman.
                 The #forms section lists 12 official MDHHS forms and
                 publications, hosted locally in assets/forms/mdhhs/.

timesheets.html  The Merciful Home Care Monthly Provider Log Sheet
                 (assets/forms/mhc-monthly-provider-log-sheet.pdf), how to fill
                 it in, where to submit it, and the paystub section above.

The MDHHS files were downloaded from the state on 18 August 2026. MDHHS revises
them periodically. To refresh, pull the current versions from
michigan.gov/mdhhs/adult-child-serv/adults-and-seniors/forms-pubs and overwrite
the files in assets/forms/mdhhs/ using the same filenames. No HTML edit needed.
The page already links out to that official library as the always-current source.
